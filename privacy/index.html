Privacy policy

SEO Gets · last updated 17 November 2026

Who uses SEO Gets

SEO Gets is a private tool used only by its owner to manage the owner's own websites. It is not offered to other people.

What data it accesses

When the owner connects their Google account, SEO Gets uses Google APIs with the permissions the owner grants:

  • Google Search Console API — search performance data and the list of properties for the owner's own websites, and adding the owner's sites as properties;
  • Site Verification API — verifying that the owner controls their websites;
  • Indexing API — notifying Google that pages on the owner's websites were updated.

How the data is used and stored

The data is used only to show the owner reports about their own websites and to perform the actions above at the owner's request. It is stored locally on the owner's computer. It is not sold, shared with third parties, used for advertising, or used to train AI models.

SEO Gets' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time in the Google account's third-party access settings. Disconnecting the account in SEO Gets deletes the stored access tokens; the owner can delete the locally stored reports at any time.
